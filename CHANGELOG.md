# Changelog

## 1.0.0 — prepared for initial release

- Native, offline color and image workspaces for macOS and iPadOS.
- Color selection, named-color browsing, conversion, accessibility checking,
  and color-vision simulation.
- Palette and gradient authoring, local projects and collections, backups,
  and file exports.
- Pixel sampling, palette extraction, image transforms, recoloring, and
  on-device foreground masking where supported.
- No bundled AI upscaling model.
