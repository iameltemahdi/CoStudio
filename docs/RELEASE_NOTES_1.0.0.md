# CoStudio 1.0.0

CoStudio brings color, palettes, gradients, accessibility, and image editing
together in a native Mac and iPad workspace.

- Capture exact colors, browse named swatches, or sample an image with a loupe.
- Build palettes and gradients, organize local collections, and export to
  design and engineering formats.
- Check text contrast, preview common color-vision deficiencies, and inspect
  perceptual color spaces.
- Edit separate copies of images, with local foreground masking where
  supported by Apple Vision.

AI upscaling is not included. Projects, preferences, and images stay on the
device unless you choose where to export them.
