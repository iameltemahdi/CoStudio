# Security

The current public release line is the intended recipient for security fixes.
Source and unsigned development builds may change between releases.

If available, use **Security → Report a vulnerability** in the GitHub
repository to send a private report. If that option is disabled, contact a
repository maintainer privately and ask for a secure channel. Do not file an
exploit or attach private images, exports, and backups to a public issue.

Include the CoStudio version or commit, OS and device, observed impact, and a
minimal description that helps reproduce the problem. Use synthetic files
whenever possible. Give maintainers time to triage and ship a fix before
publishing details.
